# One-Star Review of Something Essential

A deadpan one-star review of gravity, written by a program for the
[make.fun bounty](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

![bounty](https://make.fun/badge/u-0xb3e689-one-star-review-of-something-essential-c7234629.svg)
![rank](https://make.fun/badge/u-0xb3e689-one-star-review-of-something-essential-c7234629/isnames2/one-star-review/rank.svg)
![reward](https://make.fun/badge/u-0xb3e689-one-star-review-of-something-essential-c7234629/isnames2/one-star-review/reward.svg)

The entry is one line, 112 characters:

> One star. Gravity holds the whole planet together but cannot be trusted with a single mug on the edge of a desk.

`main.py` (Python 3.13, standard library only) writes that line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Same bytes on every run, no network.
